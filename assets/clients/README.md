Archive sources accessed October 23, 2026; the other six client sources were
accessed October 24, 2026. `provenance.json` records exact download URLs,
dimensions, product roles, packaging and original/packaged SHA-256 hashes.
`light` and `dark` name the intended background.
Preserve the original aspect ratio, artwork, colors, and clear space. Use
separate image elements rather than combining vendor SVGs or recoloring them.
VS Code's blue stable icon is used for documentation, not a partner badge.

Original downloads:

- Cursor: `https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/brand/cursor-brand-assets.zip`
- OpenCode: `https://opencode.ai/opencode-brand-assets.zip`
- VS Code: `https://code.visualstudio.com/assets/branding/visual-studio-code-icons.zip`

Every client has a visible product name beside its mark. Codex uses the shared
OpenAI family artwork supplied for its official extension, not a claimed unique
Codex symbol. Claude Code and Desktop use official Claude family artwork, with
distinct labels. Antigravity uses its official product-family mark, not Gemini.

Keep original backgrounds and transparency: Codex's black square, Claude Code's
terracotta disk and Hermes's white tile are part of the supplied artwork.
The Antigravity SVG preserves its original color-scheme rule. Claude Desktop's
32px source is suitable for the 24/32px documentation slots, not a large hero.
No raster resampling, tracing, cropping, recoloring or substitute marks are used.
